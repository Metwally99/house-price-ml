# House Price Prediction · Neural Network Experiments

A PyTorch and Flask project comparing five regression architectures, from a linear baseline to wider and deeper neural networks.

## What is included

- Training code for five models, with train/test splitting, feature scaling, and mean squared error evaluation.
- Saved model weights and feature scaler generated by the training script.
- A Flask prediction API and a model-selection interface.

## Setup

```bash
python -m venv .venv
pip install -r requirements.txt
```

Activate your environment, then place a compatible CSV at `data/houses.csv` or set `DATASET_PATH` to its path. The script expects eight columns in this order: serial, date, age, distance, stores, latitude, longitude, price. The dataset is not included.

Run `python train_models.py` to generate model artifacts, then `python app.py` to start the local application. Set `MODEL_DIR` to change the model directory for both commands.

This project is an educational experiment. Evaluation numbers depend on the dataset and are not asserted here.
